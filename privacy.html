Privacy Policy

Countdown Peak Uploader · last updated 17 November 2026

Who uses the app

Countdown Peak Uploader is used only by the owner of the Countdown Peak YouTube channel to manage that channel. It does not collect data from any other people.

What data the app accesses

With the owner's permission (Google OAuth), the app uses the YouTube Data API to upload and schedule videos, set thumbnails, update video titles, descriptions and tags, read the channel's video list and statistics, and post comments on the channel's own videos.

How data is stored

The access token is stored only on the owner's computer. No data is sent to any third party, sold, or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
